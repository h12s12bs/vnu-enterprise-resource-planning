## ⏱️ 每週上課進行節奏 (100 分鐘標準配比)

- **【前半段】第一節 (50 分鐘) — 核心觀念精講與考點解析：**
  - `00~10 分鐘`：破冰引言、時事企業案例與營運痛點導入。
  - `10~40 分鐘`：單元核心流程觀念精講、模組架構圖解與資料流向剖析。
  - `40~50 分鐘`：高頻精選考題實戰演練與解題盲點破解。
- **【後半段】第二節 (50 分鐘) — 流程實戰、情境演練與 AI 實務：**
  - `00~35 分鐘`：一人一機下載 Antigravity 專案包，動手實作 Python 企業程式與流程驗收。
  - `35~45 分鐘`：操作易錯防呆提醒、觀念統整與成果檢核 (verify.py)。
  - `45~50 分鐘`：單元總結、線上隨堂快測 (5題) 檢測與指派課後複習題。

## 🌟 平台五大核心功能模組

1. **📅 18 週課程教學進度與課堂指引**：
   - 完整收錄 18 週教學大綱、每週核心觀念卡、痛點對比、專屬模擬器捷徑與隨堂 5 題快測。
2. **💻 Antigravity 電腦教室實戰專案包 (每週一案)**：
   - 全套 18 週獨立實作專案包（內含 `starter.py`、`sample_data.json`、`verify.py`、`README.md` 任務指引）。
   - 一鍵複製 Antigravity 提示詞、一鍵下載專案 ZIP 包，一人一機在電腦教室動手產出真實企業成果！
3. **🤖 Agentic AI 企業流程規劃實驗室 (AI Studio)**：
   - 4 大企業實務 Agent 範本：**O2C 智慧銷售訂單代理**、**P2P 發票三向核帳代理**、**MRP 預警補貨代理**、**CRM 售後退換貨代理**。
   - **視覺化 Agent 規劃畫布**：配置 Trigger ➔ Prompt ➔ ERP API Tools ➔ Guardrails 門檻 ➔ Human-in-the-Loop 人機審核。
   - **ReAct 推理引擎動態模擬**：逐步動態展示 Thought ➔ Action ➔ Observation ➔ Final Decision 思考軌跡。
   - **期末專題提案產生器**：一鍵產生並匯出「Agentic AI 專題企劃書」（期末專題評分佔比 10%，支援列印與下載 Markdown）。
4. **🎯 ERP 實務檢定與題庫測驗中心**：
   - 收錄 15 章教材題庫 (180 題) ＋ 最新 20+ 題 AI-ERP 前瞻考題（共 200 題完整題庫）。
   - 支援「每週 5 題快測」、「章節練習」、「期中 50 題全真模考 (60分鐘)」與「期末 100 題衝刺 (100分鐘)」。
   - 70 分及格判定，提供各 ERP 模組落點雷達分析與逐題邱老師考點解析。
5. **🏆 學習成就與錯題筆記本**：
   - 學生設定學號與姓名即可解鎖 8 大榮譽勳章。
   - 做錯的題目自動收錄至「錯題筆記本」，方便考前精準重練！

## 🚀 平台三大多元使用模式

### 模式一：線上雲端正式版 (GitHub Pages + Firebase 登入) 🌟【最推薦】
- **網址：** [https://h12s12bs.github.io/vnu-enterprise-resource-planning/](https://h12s12bs.github.io/vnu-enterprise-resource-planning/)
- **特色功能：**
  1. **Firebase Google 帳號授權登入**：支援一鍵使用學校 Google 帳號或個人 Gmail 快速登入。
  2. **學號／姓名智慧綁定**：初次登入自動彈窗綁定學生學號與姓名，測驗紀錄與成就自動同步至雲端 Firestore 資料庫，跨裝置不遺失。
  3. **教師管理員權限**：教師 (邱俊維 博士) 登入後自動識別教師身份，可一鍵匯出全班學生作答與測驗成就 Excel 總表。
  4. **全套教材直接下載**：18 週教學簡報 PPTX 與每週 Antigravity 實戰專案 ZIP 包均可在線上隨時下載。

### 模式二：電腦教室區域網路互動模式 (校園局域網)
1. 在教師主機上，直接雙擊點擊 **`啟動教學平台.bat`**。
2. 系統會自動啟動後端伺服器，並開啟預設瀏覽器至 `http://localhost:5000`。
3. 命令提示字元與平台右上角會顯示電腦教室的區域網路網址（例如：`http://120.124.20.34:5000`）。
4. **請老師將該網址投影至大螢幕**，全班學生於座位電腦打開 Chrome 或 Edge 瀏覽器輸入該網址即可同步連線操作！

### 模式三：單機離線免安裝模式 (零網路環境備援)
- 若教室無網路或有防火牆阻擋，可直接將 **`平台首頁(單機離線直接點開).html`** 發送給學生（或放至隨身碟/Google 雲端硬碟）。
- 學生雙擊該 HTML 檔案即可在任何瀏覽器中離線運行所有模擬器、Agentic 實驗室與 200 題題庫練習！
